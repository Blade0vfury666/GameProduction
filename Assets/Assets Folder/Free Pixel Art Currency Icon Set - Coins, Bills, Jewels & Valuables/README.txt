TIPS FOR PIXEL-PERFECT RENDERING
--------------------------------------------------------------------------------
 
  - Always display icons at exact multiples of 32px (32, 64, 96, 128...).
    Displaying at non-integer scales (e.g. 50px or 90px) will cause blurring
    or anti-aliasing artifacts.
 
  - In CSS, use:
      image-rendering: pixelated;
    to preserve the crisp pixel look when scaling in the browser.
 
  - In Photoshop and Affinity, use "Nearest Neighbor" as the interpolation
    method when resizing.
 
  - In Unity, set the Texture Type to "Sprite" and Filter Mode to "Point (no
    filter)" for correct rendering.
